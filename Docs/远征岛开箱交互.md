# 远征岛开箱交互

你正在 A 区挖坑，另一队在 C 区开了一只箱子。赛后揭晓是假箱，抽到「翻砂成坡」。全房海图把原箱位画成灰叉，C 区坑边翻起一段砂坡。近处的人可以先借坡登高，远处的人可以留在原来的坑里继续挖。若抽到「船员集合」，分头找箱的队员则会聚回本队一名队友的勘探点。只有真箱才给开箱队和胜队发本区坐标和碎片。

| 时刻 | 玩家看到什么 | 接下来能做什么 |
|---|---|---|
| 第一次打开普通箱 | 箱子接受全房挑战，开箱人和远处玩家同时看到冷色墨潮从视野边缘卷入。此时开始加载小游戏，原来的开箱操作条收起，左上只留下「宝箱已开启 · 仍可移动」。箱子外观与游戏种类都不透露真假。 | 前 1.35 秒仍可移动、转头，当前这一只箱已被占用。 |
| 混沌完全盖黑 | 每端只在自己的画面完全黑后锁住角色。屏幕的黑色遮住视角与角色交换，全房就绪后，黑幕约用 0.85 秒揭开新场地。 | 看目标与倒计时，再用小游戏的移动、跳跃和挖填参赛。黑屏时持续按键不会把主岛动作带进新关。 |
| 小游戏结束 | 先看个人赛成绩或迷宫阵营胜负。返回时混沌约用 1.05 秒重新合拢，旧场地卸载、原岛就绪后，再用约 0.85 秒显出岛景。 | 回到岛上继续走。奖励展示等到本地转场结束、全房恢复寻宝后才计时。 |
| 再次靠近已揭晓的真箱 | 箱盖保持打开。本队尚未领过碎片时，箱边显示「E 领取钥匙碎片」。 | 按一次 E 为全队领取碎片和点位，其他玩家继续在岛上寻宝。 |
| 本队首次获得某一真箱的奖励 | 右下海图短暂展开。对应的搜索圆在约 0.9 秒内收至真实箱位，留下带区名字母的点。旁边一段金色钥匙部件归位，左上库存同步增加。 | 保持准星与移动方向，按住 Tab 可在大海图上看同一次落点。两种图都显示自己队伍已获的点。 |
| 第三片到账 | 拾取反馈持续 1.25 秒，随后钥匙环、轴和齿用 0.8 秒合拢。左上改为「队伍钥匙」，提示再找一处真箱定位最终宝藏。 | 辨认海图上唯一剩下的搜索圈，继续寻找最后一点。 |
| 第四个点到账 | 第四片作为余片入账。A、C 与 B、D 两组端点约用 0.8 秒向交点绘线，金叉与「最终宝藏」随即出现。 | 跟随屏幕上方的方位和水平距离前进。到交点两米内，提示变为「在脚下挖宝」。 |
| 假箱结算 | 全房揭晓同一个事件，原箱位在海图留下灰叉。 | 根据事件选下一步。抽到「开路好手」的胜队可挖宽洞，抽到「停火潮」的各队都可趁机接近箱锁。 |
| 打开最终宝箱 | 服务器裁定胜队并消耗一把钥匙。奖箱保持打开，金色罗盘升起。结算镜头从挖出的实际空间选取能看见箱盖与罗盘的角度。站在箱上挡住镜头的角色会在本地特写中隐去。右侧保留本队海图，已知交点盖上「已取宝」金印。 | 全房看到结算。房主可返回房间再开一局。较窄的画面优先保留现有结算按钮和镜头。 |

每只真箱只在首次开启时触发小游戏。结算时，开箱队和每支小游戏胜队各得一份奖励。其他队之后到箱边领取，每队每箱限领一次。一名队员领取后，在别处的队友也会看到拾取反馈。已经领过本箱时，地图保留原点位，库存和合成动画都不会再播放。其他队可从公开结果得知在哪一区发现了真箱。所有人零分时，开箱队照样能从真箱取得碎片。

## 每只假箱随机触发一个事件

房主或来宾在岛上挖出普通箱，松开挖掘键，靠近瞄准箱盖再单击左键，首次开启会让全房参加小游戏。赛后揭晓为假箱时，房主端依据在场阵容、成绩和岛上实况，从八种事件里抽一件适用的，消耗箱子并向所有人公布。个人赛第一名代表全队获胜，迷宫抓齐逃方时多支追方队可以一起获胜。开箱者也按自己的队伍成绩结算。

| 可能抽到的事件 | 抽取条件 | 返岛后可以怎样玩 |
|---|---|---|
| 船员集合 | 在场至少一支多人队，且有队员能安全靠拢 | 多人队以本队一名队友入场前的勘探点为集合地点。能在附近站稳的队员一起返岛，单人成队或找不到安全站位的队员按常规方式返岛。 |
| 翻砂成坡 | 假箱附近有可安全成坡的地面 | 灰叉旁的地面一次翻出砂坡。全房都能踩着坡尝试登高，或直接开铲改变坡形。之后的小游戏会保留玩家留下的地形。 |
| 风卷帆布 | 岛上有可用的栈桥遮视帆 | 风把帆收放一次。落帆遮挡视线和名牌，卷帆恢复视野。帆的变化独立于栈桥的破坏进度。 |
| 开路好手 | 至少有一支胜队 | 胜队每个人都可在自己原先的位置继续开路。左键一铲的覆盖半径翻倍，右键泥团落地的堆土半径也翻倍，沿着坑壁更容易铺出能站人的宽坡。单次挖深、台高、射程和眩晕规则沿用常规值。强化持续至下一场小游戏正式开始。 |
| 乱流冲散 | 至少有一支队伍未获胜 | 胜队按原位返岛。败队成员各自落到岛上随机选出的安全地面，同队也可能被分开。先看地标或按住 Tab 认路，有队友时可按 G 约个集合点。位移只在返岛时发生一次。 |
| 迷雾换装 | 至少两名玩家仍在场，队伍可以相同 | 全员在原处穿上相同装束，头顶名牌隐藏，原有集合信号暂不可见，也不能发新信号。想在雾中会合，可以事先约定在断拱或码头见。 |
| 弹跳潮 | 单人、组队均可 | 全员在岛上的普通跳跃初速度提高至 1.5 倍。原本要垫一层土才能攀出的坑沿，可以先试着从坑底直接跳上去。 |
| 停火潮 | 至少有两支队伍仍在场 | 泥团打中对手不会累积泥印或触发新眩晕，打在地上仍能堆土。各队可以趁机铺坡接近宝箱，合撬和夺锁继续按原规则进行。 |

每箱只在成功结算时抽一次。符合条件的项目机会相等，不同箱子可以连续抽到同一事件。例如，三人分成两队，一胜一负，两名队友能安全集合，场上有可收放的帆架且假箱旁能成坡时，八种事件各占八分之一。若所有帆架都已拆掉，这一箱就从其余七项中抽。独自出航也可能遇到砂坡或帆布翻动，取决于现场条件。单人获胜时另有开路好手、弹跳潮可抽。单人零分时另有乱流冲散、弹跳潮可抽。

船员集合和乱流冲散各只安排一次落点。其余事件按原位返岛，原处受阻时沿用安全落点。砂坡、帆布改变的是岛上的实物，下一场开赛后仍保留，之后可以挖坡、堆土、收帆或拆掉帆架。开路好手、迷雾换装、弹跳潮和停火潮都持续到下一场小游戏正式开始，整局寻宝结束时也会清除。补领已揭晓的真箱只更新本队进度。下一场加载中止时，房主与来宾回到岛上，仍可使用原有效果，也能重开同一只箱。

房主与来宾看见相同的事件和假箱灰叉。每队的碎片、钥匙和已领点位保持原值，领完第四只真箱才画出藏宝交点。一名队员领取真箱时，信息会同步给全队。

## 假箱事件验收用例

| 走查安排 | 本次应核对的结果 |
|---|---|
| 两名队友分头找箱，一名对手单独成队，抽到船员集合 | 房主与来宾可互换队伍。两名队友在本队原勘探点附近分别安全落地，单人成队的对手按原位返岛。若两队各有多名成员，分别检验各自的集合点。 |
| 假箱旁有可改造地面，抽到翻砂成坡 | 房主和来宾都能踩上同一段坡，左键能重新挖开。重新进入一场小游戏再返回，坡面保留最后的挖填状态。 |
| 有完好的栈桥遮视帆，抽到风卷帆布 | 两端从帆前观察视线和名牌。检查栈桥的发动进度，再拆光遮视帆验证假箱的候选池。 |
| 三人分两队，胜者还有一名队友 | 抽中开路好手时，胜队两人可分别挖出宽洞、铺出宽台，败队原地返岛。另一个箱抽中乱流冲散时，只有败队玩家换位置，胜队工具使用常规宽度。三端各新增同一灰叉，碎片和点位保持原值。 |
| 两个同队玩家在相邻路口，抽到迷雾换装 | 两端看到相同装束，对方名牌与集合信号隐藏，仍能看本队线索并挖填。回岛后停留多久都保持雾衣。下场正式开赛后身份恢复，再次回岛可使用集合信号。 |
| 两队在同一处可重复的坑边或箱锁旁 | 弹跳潮中测量两端同高度起跳的最高点，事件结束后再跳一次。停火潮中用三团土直击对手，检查是否可以继续移动和开锁；往地面投土检验土台。 |
| 单人分别获胜、零分，再组迷宫两支追方同胜 | 先核对砂坡位置和可用帆架，通过检查的场景事件对单人开放。获胜另可抽开路好手与弹跳潮。零分另可抽乱流冲散与弹跳潮。迷宫若抽开路好手，两支胜队全员都强化。 |
| 有人断线、进入下场缺少加载回执，随后重开同一只箱 | 抽取时的条件与仍在线的参赛者一致。取消进入时回到原岛，同一只箱仍可重开，未结算的箱不消耗。正式结算一次只产生一项事件，一个灰叉。 |
| 带着持续效果补领真箱，再打开新箱 | 补领只更新本队真箱进度。开启新箱进入加载时，原有效果保留。让一位来宾加载失败，全房回岛仍有同一效果。重试并正式开赛时，各端一起清除效果。 |
