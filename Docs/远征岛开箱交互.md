# 远征岛开箱交互

四处真箱各给本队一个点位和一枚碎片。第三片自动合成钥匙，第四处真箱补全藏宝交点，并留下一片余片。玩家从开箱、看图走到交点挖宝。收碎片、合钥和收图都可边走边看。

| 时刻 | 玩家看到什么 | 接下来能做什么 |
|---|---|---|
| 第一次打开普通箱 | 箱子接受全房挑战，开箱人和远处玩家同时看到冷色墨潮从视野边缘卷入。此时开始加载小游戏，原来的开箱操作条收起，左上只留下「宝箱已开启 · 仍可移动」。箱子外观与游戏种类都不透露真假。 | 前 1.35 秒仍可移动、转头，当前这一只箱已被占用。 |
| 混沌完全盖黑 | 每端只在自己的画面完全黑后锁住角色。屏幕的黑色遮住视角与角色交换，全房就绪后，黑幕约用 0.85 秒揭开新场地。 | 看目标与倒计时，再用小游戏的移动、跳跃和挖填参赛。黑屏时持续按键不会把主岛动作带进新关。 |
| 小游戏结束 | 先看个人名次。返回时混沌约用 1.05 秒重新合拢，旧场地卸载、原岛就绪后，再用约 0.85 秒显出岛景。 | 回到岛上继续走。奖励展示等到本地转场结束、全房恢复寻宝后才计时。 |
| 再次靠近已揭晓的真箱 | 箱盖保持打开。本队尚未领过碎片时，箱边显示「E 领取钥匙碎片」。 | 按一次 E 为全队领取碎片和点位，其他玩家继续在岛上寻宝。 |
| 本队首次获得某一真箱的奖励 | 右下海图短暂展开。对应的搜索圆在约 0.9 秒内收至真实箱位，留下带区名字母的点。旁边一段金色钥匙部件归位，左上库存同步增加。 | 保持准星与移动方向，按住 Tab 可在大海图上看同一次落点。两种图都显示自己队伍已获的点。 |
| 第三片到账 | 拾取反馈持续 1.25 秒，随后钥匙环、轴和齿用 0.8 秒合拢。左上改为「队伍钥匙」，提示再找一处真箱定位最终宝藏。 | 辨认海图上唯一剩下的搜索圈，继续寻找最后一点。 |
| 第四个点到账 | 第四片作为余片入账。A、C 与 B、D 两组端点约用 0.8 秒向交点绘线，金叉与「最终宝藏」随即出现。 | 跟随屏幕上方的方位和水平距离前进。到交点两米内，提示变为「在脚下挖宝」。 |
| 赢下假箱小游戏 | 返岛后右下用约 2.25 秒显示「优胜情报 · B 区真箱已标记」（字母随点位变化）。本队每个成员都能在原搜索圈内看到空心金色菱形。 | 按住 Tab 找到精确位置，前去挖箱。本队领到该箱的碎片时，菱形变为实心点。 |
| 打开最终宝箱 | 服务器裁定胜队并消耗一把钥匙。奖箱保持打开，金色罗盘升起。结算镜头从挖出的实际空间选取能看见箱盖与罗盘的角度。站在箱上挡住镜头的角色会在本地特写中隐去。右侧保留本队海图，已知交点盖上「已取宝」金印。 | 全房看到结算。房主可返回房间再开一局。较窄的画面优先保留现有结算按钮和镜头。 |

每只真箱只在首次开启时触发小游戏。结算时，开箱队和每支小游戏胜队各得一份奖励。其他队之后到箱边领取，每队每箱限领一次。一名队员领取后，在别处的队友也会看到拾取反馈。已经领过本箱时，地图保留原点位，库存和合成动画都不会再播放。其他队可从公开结果得知在哪一区发现了真箱。所有人零分时，开箱队照样能从真箱取得碎片。

假箱在小游戏结算后才揭晓，消耗一次，所有人的海图都在该处盖上灰叉。房主用本局种子的独立随机序列选择以下两种效果之一。六款体素小游戏是比赛场地，真箱和假箱都可以进入。

假箱比赛第一名的队伍额外取得一处此前既未侦察、也未领取的真箱坐标。图例「优胜情报 · 本队未领」只出现在赢家队伍的海图上。碎片数和已领真箱数保持原值。三处已领加一处侦察时，玩家可以循菱形找第四处，取得该箱奖励后才会显出最终宝藏。全队已经掌握四个位置时，回岛提示「本队已标全真箱位置」。全员零分则没有赢家，没人获得新坐标。雾衣期间仍用私有海图发放情报，公开提示继续隐藏赢家身份。

| 假箱事件 | 返岛后的效果 | 玩家如何恢复方位 |
|---|---|---|
| 乱流换位 | 全员从不同的陆侧方向寻找可站立的安全落点，离开原先挖掘的位置。既有碎片、钥匙和海图点位保留。 | 回岛提示「乱流将所有人冲到了新的落脚点」。看海图上的「你」、码头或既有目标，重新选择路线。 |
| 雾衣伪装 | 全员身份混淆 120 秒。角色改用统一外观色，姓名、队标、集合点和队友在图上的指示暂时隐藏。碎片和开箱资格仍按原队结算。 | 左上显示「身份迷雾」及剩余时间。海图仍画自己和已获点位，倒计时结束恢复平时的身份提示。 |

小海图、拾取部件和方位提示都由 HUD 绘制，不取得鼠标焦点，也不自动打开 Tab 大地图。暂停期间奖励停在当前阶段，恢复操作后接着播放。断线、载入失败或中断返岛时，以房主确认的结算与本地可靠快照为准，未确认的箱子不给拾取反馈。即使另一队先打开大奖，结算图也只保留本队曾获的点位。


## 实机复验

新版 Mac 试玩包在同一台 Mac 上用三个独立游戏进程复验 A 箱。第 1 队首次开启并获胜，第 2 队随后在箱边按 E，碎片从零增至一枚。第 2 队再次按 E 收到已领提示，第 3 队仍为零枚。两次复验中三端都留在岛上，小游戏场数均保持为一。[正常网络](../ActDemo/Saved/ChestFirstOpenMac/games/normal/summary.json) · [模拟 80 毫秒往返延迟、2% 丢包](../ActDemo/Saved/ChestFirstOpenMac/games/emulated/summary.json)

早期 Mac 试玩包曾用三端核对六张小游戏地图、假箱情报和最终大奖。当时复访 A 箱会再打一场比赛，因此这两份旧记录含七场小游戏。[旧版普通网络记录](../ActDemo/Saved/ChestSixMacProof/games/normal/summary.json) · [旧版模拟丢包记录](../ActDemo/Saved/ChestSixMacProof/games/emulated/summary.json)

双 Metal 窗口另检查了同队共享情报与跨场输入。房主和来宾在入场渐暗时各走了 44.3 和 48.0 厘米，退场渐暗时各走了 59.1 和 67.2 厘米。四张切换黑帧均为纯黑，两端在黑屏中按住前进的输入增量均为零。返岛后两端都看到同一枚 D 区菱形，碎片数与正式点位数仍为零。[双窗口实机记录](../ActDemo/Saved/ChestInteractionDualMetalPackage/games-crew/normal/summary.json)
