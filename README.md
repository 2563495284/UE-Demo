# 远征岛 · 体素海岛寻宝

解压 [远征岛 Mac 试玩包](Builds/TreasureIsland/Mac/远征岛-Mac.zip)，双击「远征岛.app」进入码头首页。游戏会自动以游客身份连接 EOS。房主创建房间，朋友通过互联网公开列表按房名加入，无需注册、登录或填写 IP 地址。1–8 名玩家自由组队，在远征岛上挖掘、收集线索、争夺大奖。单人可以直接开局。

首次启动默认使用 1280 × 720 窗口。在首页、码头或对局中的 Esc 菜单打开「游戏设置」，可以切换简体中文和 English，调整窗口模式、分辨率、画质、帧率、垂直同步、总音量、视角灵敏度、Y 轴反转和镜头晃动。更改显示模式或分辨率后选择「保留并保存」。15 秒内没有确认，游戏会恢复原来的画面。设置保存在本机，下次启动继续使用。

默认用第三人称看队友和地形，按 V 可切到第一人称瞄准，再按 V 切回。按住左键一路挖，转动准星可改挖另一面。右键从开局就能独立连丢，无需先挖或攒土。泥团落地能踩，连续砸中对手三次会让他晕倒，继续丢能埋住。醒来后可以在土里另挖出口。

每局有四只真箱，A–D 四个半径 18 米的搜索区各埋一只。房主开局前可再加 0–24 只假箱，默认加 4 只。挖到箱盖后靠近按 E。每只箱首次开启时，所有玩家的画面从四周卷入墨色混沌，玩家仍能移动。全黑后才锁住角色，随后显出小游戏地图。比赛结束再以暖色墨潮回到海岛，揭晓真假。

真箱把准确坐标和一枚钥匙碎片发给开箱队和每支小游戏胜队。其余队伍随后到这只箱边按 E 即可直接领取，每队每箱限领一次。第三枚碎片自动合成队伍钥匙，第四个不同真箱的坐标才让海图画出 A–C、B–D 两条线。到交点挖出大奖，持钥按 E 开锁，队友可以合撬。第一支开锁的队伍获胜。

每只假箱结算时，房主端结合在场队伍、赛果和岛上实况，从八种事件中筛出可触发的项目，各以相同概率抽取。队伍可能被乱流冲散，也可能聚到队友原先的挖掘点。岛上还可能在假箱旁翻起可挖的砂坡，或让晒帆架一次收放，改变路口视线。宽铲、迷雾、高跳和停火这四种效果会持续到下一场小游戏正式开始或整局结束。不同假箱可以连续抽中同一项。[八种假箱事件与抽取条件](Docs/远征岛开箱交互.md#每只假箱随机触发一个事件)

至少两支队伍在场时，开箱还可能抽到迷宫追捕。一队先行，其他队在三分钟内合作抓人。左键拆墙、右键封回缺口，追方瞄准近身的逃方按右键即可砸晕抓获。被抓后跟随存活队友观战。抓齐则追方各队同胜，超时仍有人在逃则只有逃方获胜。

在六种个人赛中，左键可以就近挖棋盘，也可以瞄准外岛的建筑拆除整座设施。灯塔、桥、闸门等建筑被拆后，全房都能看到原处的缺口。

远征岛每局按种子摆放彩色中立物体。看见绿树可以敲根放倒，见到赭橙砂斗可以敲木销放砂。砖红船壳能挖通，紫帆绳尾按 E 收放，蓝色潮孔封住一边后可以借另一边的水柱跳到约 13.5 米外。主岛的码头、地标、路标和五类中立设施都可用左键拆除，其他队随后经过会看到同样的缺口。[摆放与操作](Docs/Expedition.md#中立场景物体)

## Mac 构建与启动

安装 Unreal Engine 5.8 和 Xcode，运行以下命令编译编辑器目标，再从源码启动游戏前台。也可打开 `ActDemo/ActDemo.uproject`，在编辑器中选择关卡和 PIE 联机设置。

```sh
bash Scripts/actdemo.sh build
bash Scripts/actdemo.sh play
```

引擎路径可通过 `UE_ROOT` 覆盖。从源码运行互联网大厅和打包时，将本产品的 EOS 游戏客户端参数填入 `ActDemo/Config/Mac/MacEngine.ini`，字段见同目录的 `MacEngine.ini.example`。运行 `bash Scripts/actdemo.sh package` 会在 `Builds/TreasureIsland/Mac` 同时更新「远征岛.app」和「远征岛-Mac.zip」。压缩包内附[试玩说明](Docs/试玩说明.txt)。`island-package` 与 `voxel-package` 沿用同一发行目录。跨网双机验收见[公网大厅验证](Docs/Expedition.md#公网大厅验证)。要进入旧版体素测试地图，可运行 `voxel-host`。

## Git 与资源协作

Git LFS 管理 UE 地图、资源与可编辑素材。克隆后在仓库根目录执行以下命令，确认资源下载成功后再打开 UE。

```sh
git lfs install --local
git lfs pull
git lfs locks
```

修改已有二进制资源前先同步分支，并用 `git lfs lock` 锁定对应路径。资源与依赖的代码、配置随提交一起推送，合入主分支后用 `git lfs unlock` 解除锁定。生成命令使用 `-Force` 覆盖地图时也采用同样的锁定流程。`.lfsconfig` 启用推送前的锁检查。
